The problem

Detection is easy to claim. It's impossible to prove.

Regulated firms must demonstrate their surveillance models catch market abuse.
  • Real trading data isn't labelled — nobody tags which trades were spoofing.
  • So there's no ground truth to measure a detector against.
  • The hard problem isn't detection — it's validation. That's the gap.

ProvingGround02 / solution
How it works

One deterministic loop, end to end.

  • generate / inject — clean stochastic order flow, then a planted spoof (large order far from mid, cancelled before it fills) with labelled ground truth.
  • detect / score — run both detectors; compute catch rate, false-positive rate, precision, and a drill-down into every miss (order book + why it was manipulation).
  • attest / verify — write the scored run to Walrus; verify by re-fetching and recomputing the hash. Tamper a byte → verification fails.
  • calibrated to a real market — the live DeepBook SUI/USDC book seeds the realism.
